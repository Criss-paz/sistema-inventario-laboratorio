Cómo se restaura

La restauración reemplaza todos los datos actuales, por eso no se hace desde esta pantalla. La realiza quien administra el servidor, con psql, siguiendo el manual técnico (docs/entrega-4/ENTREGA4_MANUAL_TECNICO.md, sección «Respaldo y restauración»):

psql -v ON_ERROR_STOP=1 -d inventario_laboratorio -f {{ archivo }}

Corre en una sola transacción: si algo falla, la base queda exactamente como estaba.
